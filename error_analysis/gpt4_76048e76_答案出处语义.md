> 类型：temporal-reasoning（时间推理，跨会话）

| answer | `bike` |
| answer_session_ids | `['answer_b535969f_2', 'answer_b535969f_1']`（= 全部 2 个 session） |

## 2. 推理链（正确）

| 事件 | 时间 | 证据位置 |
|---|---|---|
| 自行车送修 | 2 月中旬 | session `b535969f_2`，turn1（"in mid-February, I had to take it in for repairs"）、turn11 |

## 3. 争议点：session#2 被标「答案出处」是否错误？

### 表面观感
session#2（`b535969f_1`）只提供「汽车 2/27 清洗」这一个时间点，**单独无法推导出答案**（不知道自行车事件）。因此初看，把它标记为「答案出处」显得不严谨。

### 官方语义（查证 README 原文）
`has_answer: true` 与 `answer_session_ids` 的官方定义是：

> - `has_answer`：**包含所需证据（required evidence）** 的 turn，用于 turn-level memory recall 评估。
> - `answer_session_ids`：代表 **evidence sessions（证据会话）**，用于 session-level memory recall 评估。

即：**标注的不是「能独立得出答案的会话」，而是「回答问题所需的证据所在」。**

### 官方 oracle 文件佐证
`longmemeval_oracle.json`（仅保留证据会话）中，本样本**同时保留 2 个 session**，各含 1 条 `has_answer` 消息。官方明确把两个会话都视为证据——因为缺任一无法完成推理。

### 结论
- **数据标注并非错误**：session#2 确实是推理所需的证据会话之一，标记符合官方语义。
- **「不严谨」感来源于标签措辞**：把 `answer_session_ids` 译作「答案出处」误导了直觉；准确应译为「证据所在/证据会话」。
- 浏览器前端已据此把标签统一改为「★ 证据」/「证据」，避免语义混淆。

## 4. 真正的数据标注隐患（本镜像特有）

1. **`answer_session_ids` 无区分度**：50% 样本（500/1000）该字段恒等于全部 session 列表。判断证据必须用**消息级 `has_answer`**，不要依赖 `answer_session_ids`。
2. **session 顺序与时间顺序不一致**：本样本两个 session 按降序存储（22:50 在前、08:11 在后）。全数据集约 29.7% 的多 session 样本非时间升序。**流转换 / Memory 处理必须按 `haystack_dates` 重排 session。**
3. **跨窗口聚合是核心难点**：56.6% 样本答案证据分布在 ≥2 个 session，本样本即典型——答案需要综合两个会话的两条时间事实做比较，缺一不可。

## 5. 对 Memory Sidecar 实验的启示

- Memory 必须**跨 session 累积**两个时间点事实，并在最终推理时保留两者的先后关系（不能只记「自行车二月中维修」，还要记住「汽车 2/27 清洗」用于比较）。
- 评估时**不得**把「单个证据会话」当作 oracle 上限——对这类题，oracle 是「全部证据会话的并集」。
- 时间推理题需警惕：即便 Memory 正确记录了每一条事实，若丢失跨事实的时序比较上下文，仍会答错。

## 6. 复现

```python
from datasets import load_from_disk
ds = load_from_disk('data/longmemeval_s')
q = "Which vehicle did I take care of first in February, the bike or the car?"
row = next(r for r in ds if r['question'] == q)

# 按时间重排 session
from datetime import datetime
def parse(dt): return datetime.strptime(dt, '%Y/%m/%d (%a) %H:%M')
order = sorted(range(len(row['haystack_sessions'])),
               key=lambda i: parse(row['haystack_dates'][i]))

# 提取全部证据消息（跨 session）
evidence = [m for i in order for s in [row['haystack_sessions'][i]] for m in s
            if m.get('has_answer')]
```
